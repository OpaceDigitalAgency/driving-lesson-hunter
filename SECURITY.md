# Security Policy

Security fixes are considered for the latest version on the default branch.

Do not disclose a suspected vulnerability or sensitive test data in a public issue. Use this repository's **Security** tab and **Report a vulnerability** option where available. Include the affected commit, impact and safe reproduction steps, without API keys, passwords, personal data or other secrets.

If private reporting is unavailable, contact [Opace Digital Agency](https://opace.agency/get-in-touch) and identify this repository. Reports are reviewed on a best-effort basis; this policy does not create a support SLA.
